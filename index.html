Homepage focus

Frequently Examined Points

Quick chapter summaries and high-yield revision targets for DSE-style preparation.

Core A

Information Processing

A1 information systems and IPO, A2 data hierarchy/control, A3 representation, A4 spreadsheet analysis and A5 simple database/DBMS operations.

Core B

Computer System Fundamentals

CPU, memory, storage, operating system functions, utility software, system performance and suitable device selection.

Core C

Internet and Applications

LAN/WAN, network hardware, internet access, TCP/IP, IP, DNS, URL, protocols, internet services, web authoring, threats and security measures.

Core D

Programming

Sequence, selection, iteration, arrays, basic algorithm tracing, Python basics, testing and debugging.

Core E

Social Implications

Privacy, personal data protection, copyright, software licensing, ergonomic practice, e-waste and ethical technology use.

Elective A

Databases

SQL table maintenance, operators/functions, multi-table joins/subqueries, relational integrity, ER diagrams, normalisation and access rights.

Elective C

Algorithm and Programming

Python review, advanced control, modular programming, data structures, searching/sorting/merging, text files and device/IoT applications.
